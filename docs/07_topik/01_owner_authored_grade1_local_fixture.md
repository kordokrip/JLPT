# TOPIK 1급 자체 저작 로컬 fixture

> 상태: 테스트 전용 local fixture. 운영 TOPIK owner curriculum과 practice bank의 공개 상태를 결정하지 않는다. 운영 curriculum은 1~6급 Batch 1~3이며, 계정별 progress와 FSRS card를 사용한다.

이 문서는 API·PWA·오디오 provenance 계약을 검증하기 위한 작은 로컬 fixture다. 모든 문장, 보기, 정답, 해설은 이 저장소에서 새로 작성했으며 공식 TOPIK 기출 문항·정답·음원·대본을 포함하거나 변형하지 않는다. 외부 API 호출, 외부 파일 내려받기, R2 저장 또는 원격 D1 seed에는 사용하지 않는다.

## Unit: 인사와 자기소개

### Vocabulary pronunciation

- 학습 목표: `안녕하세요`를 처음 만난 사람에게 쓰는 인사로 이해한다.
- 문제: `안녕하세요`와 가장 알맞게 연결되는 뜻은 무엇입니까?
- 보기: 처음 만날 때의 인사 / 식당 주문 / 날짜 묻기 / 길 안내
- 정답: 처음 만날 때의 인사
- 발음 텍스트: `안녕하세요.`
- 오디오 상태: 자체 저작 발음 텍스트는 Google 한국어 음성을 우선하고 같은 언어의 브라우저/기기 음성으로 즉시 재생할 수 있다. R2 녹음 파일은 생성·연결하지 않는다.

### Listening

- 자체 저작 대본: `안녕하세요. 저는 유나예요. 처음 뵙겠습니다.`
- 문제: 말하는 사람은 무엇을 하고 있습니까?
- 보기: 자기소개 / 약속 취소 / 물건 구매 / 길 묻기
- 정답: 자기소개
- 오디오 상태: 자체 저작 대본은 Google 한국어 음성을 우선하고 같은 언어의 브라우저/기기 음성으로 즉시 재생할 수 있다. R2 녹음 파일은 생성·연결하지 않는다.

### Audio unavailable contract

- 문제: 오디오가 제공되지 않을 때 올바른 안내는 무엇입니까?
- 보기: 오디오가 준비될 때까지 기다린다 / R2 파일을 찾는다 / 다른 음성 엔진으로 바꾼다 / 무단 녹음을 재생한다
- 정답: 오디오가 준비될 때까지 기다린다
- 발음 텍스트: 없음
- 오디오 상태: 발음 텍스트가 없는 항목은 `오디오 준비 중`으로 표시하며 재생 제어를 제공하지 않는다. 텍스트가 있으면 같은 언어의 브라우저 음성만 허용하고 R2 객체 조회·저장·재생은 허용하지 않는다.
