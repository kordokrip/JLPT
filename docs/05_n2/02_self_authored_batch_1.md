# JLPT N2 자체 저작 학습 콘텐츠 — Batch 1
<!-- 운영 메타데이터(2026-08-09): specialized seed plan의 contentRows는 258, category는 14다. -->

이 문서는 개인 학습용 JLPT N2 콘텐츠의 첫 운영 batch입니다. 표제어의 일반적인
사전적 표기만 참고했으며, 한국어 설명·예문·독해 지문·문제·선택지·해설·청해 대본은
저장소 작성자가 새로 작성했습니다. 공식 JLPT 문항·정답·지문·음원은 포함하거나
변형하지 않습니다.

이 batch의 청해는 대본과 문제 선택을 위한 문장 데이터를 먼저 제공합니다. 재생 가능한 텍스트가
있고 같은 언어의 일본어 브라우저 음성이 있으면 즉시 들을 수 있습니다. Google 음성을 우선하고
R2 음원·activation·fallback은 발음 경로에 사용하지 않습니다.

## 카테고리 N2-G. 연결과 판단

### G2-1. わけではない — "~인 것은 아니다"

**구조**: 보통형 + わけではない

**흔한 오류**: 전면 부정이 아니라 "반드시 그렇지는 않다"는 부분 부정에 쓴다.

**예문**:

- 予定を変更したからといって、計画をやめるわけではない。 → 일정을 변경했다고 해서 계획을 그만두는 것은 아니다.
- 説明が短いからといって、内容が不足しているわけではない。 → 설명이 짧다고 해서 내용이 부족한 것은 아니다.

### G2-2. ことになっている — "~하기로 되어 있다"

**구조**: 동사 사전형/ない형 + ことになっている

**흔한 오류**: 개인의 순간적인 결정이 아니라 규칙·일정처럼 이미 정해진 사항에 쓴다.

**예문**:

- この施設では、利用前に受付で申請することになっている。 → 이 시설에서는 이용 전에 접수처에서 신청하기로 되어 있다.
- 資料は毎週金曜日に更新することになっている。 → 자료는 매주 금요일에 갱신하기로 되어 있다.

### G2-3. ことになる — "~하게 되다"

**구조**: 동사 사전형/ない형 + ことになる

**흔한 오류**: 화자의 의지만으로 정한 결정보다 외부 사정이나 절차로 정해진 결과에 가깝다.

**예문**:

- 相談の結果、来週から担当を交代することになった。 → 상의한 결과 다음 주부터 담당을 교체하게 되었다.
- 天候の影響で、案内会はオンラインで行うことになった。 → 날씨 영향으로 안내회는 온라인으로 하게 되었다.

### G2-4. おかげで — "~덕분에"

**구조**: 명사 + の / 보통형 + おかげで

**흔한 오류**: 대체로 좋은 결과에 쓰며, 불만이나 나쁜 결과에는 보통 쓰지 않는다.

**예문**:

- 事前に案内を読んだおかげで、手続きが早く終わった。 → 미리 안내를 읽은 덕분에 절차가 빨리 끝났다.
- 皆が協力してくれたおかげで、準備を時間内に終えられた。 → 모두가 협력해 준 덕분에 준비를 시간 안에 마칠 수 있었다.

### G2-5. せいで — "~탓에"

**구조**: 명사 + の / 보통형 + せいで

**흔한 오류**: 나쁜 결과의 원인을 말할 때 쓴다. 좋은 결과에는 おかげで가 자연스럽다.

**예문**:

- 電車が混雑していたせいで、集合時間に遅れた。 → 전철이 혼잡했던 탓에 모임 시간에 늦었다.
- 確認が足りなかったせいで、同じ質問に何度も答えることになった。 → 확인이 부족했던 탓에 같은 질문에 여러 번 답하게 되었다.

### G2-6. たとたんに — "~하자마자"

**구조**: 동사 과거형 + たとたんに

**흔한 오류**: 의도적으로 이어서 하는 행동보다 예상 밖의 즉각적인 변화를 나타낼 때 자연스럽다.

**예문**:

- 会議が始まったとたんに、質問が次々に出た。 → 회의가 시작하자마자 질문이 잇따라 나왔다.
- ドアを開けたとたんに、外の強い風が入ってきた。 → 문을 열자마자 밖의 강한 바람이 들어왔다.

### G2-7. うちに — "~하는 동안에, ~하기 전에"

**구조**: 동사 사전형/ている형/가능형 + うちに

**흔한 오류**: 상태가 바뀌기 전에 기회를 이용한다는 뜻으로 자주 쓴다.

**예문**:

- 期限に余裕があるうちに、必要な資料を確認しておこう。 → 기한에 여유가 있을 때 필요한 자료를 확인해 두자.
- 利用者が少ないうちに、受付の機械を点検しよう。 → 이용자가 적을 때 접수 기계를 점검하자.

### G2-8. ようにする — "~하도록 하다"

**구조**: 동사 사전형/ない형 + ようにする

**흔한 오류**: 한 번의 결정보다 습관·노력의 방향을 말할 때 쓴다.

**예문**:

- 誤解がないようにするため、変更点を文書で連絡する。 → 오해가 없도록 하기 위해 변경점을 문서로 연락한다.
- 忘れないようにするため、予定をカレンダーに記録した。 → 잊지 않도록 하기 위해 일정을 달력에 기록했다.

### G2-9. に対して — "~에 대하여, ~에 대해서는"

**구조**: 명사 + に対して

**흔한 오류**: 대상이나 대조의 기준을 분명히 할 때 쓰며, 단순한 위치 관계에는 쓰지 않는다.

**예문**:

- 利用者の意見に対して、担当者が丁寧に回答した。 → 이용자의 의견에 대해 담당자가 정중히 답했다.
- この基準に対して、別の考え方を示す人もいる。 → 이 기준에 대해 다른 생각을 보이는 사람도 있다.

### G2-10. に伴って — "~에 따라, ~에 수반하여"

**구조**: 명사 + に伴って / 동사 사전형 + のに伴って

**흔한 오류**: 규모가 큰 변화나 자연스럽게 함께 일어나는 변화를 설명할 때 알맞다.

**예문**:

- 利用者の増加に伴って、受付の時間を延長した。 → 이용자 증가에 따라 접수 시간을 연장했다.
- 制度の変更に伴って、案内の内容も更新された。 → 제도 변경에 따라 안내 내용도 갱신되었다.

### G2-11. ものの — "~이기는 하지만"

**구조**: 보통형 + ものの

**흔한 오류**: 앞 절을 인정한 뒤 뒤 절에서 기대와 다른 결과를 말한다.

**예문**:

- 提案には納得したものの、すぐに実行するのは難しい。 → 제안에는 납득했지만 바로 실행하기는 어렵다.
- 時間は十分にあったものの、必要な資料がそろわなかった。 → 시간은 충분했지만 필요한 자료가 갖추어지지 않았다.

### G2-12. かねない — "~할 수도 있다"

**구조**: 동사 연용형 + かねない

**흔한 오류**: 바람직하지 않은 결과의 가능성을 경고할 때 쓴다.

**예문**:

- 確認を急ぐと、大切な条件を見落としかねない。 → 확인을 서두르면 중요한 조건을 놓칠 수도 있다.
- 説明を省略すると、利用者が不安を感じかねない。 → 설명을 생략하면 이용자가 불안을 느낄 수도 있다.

### G2-13. だけに — "~이기 때문에 더욱"

**구조**: 명사/な형용사 어간 + だけに / 보통형 + だけに

**흔한 오류**: 단순한 이유보다, 그 성질 때문에 결과가 더 강하게 나타남을 말할 때 쓴다.

**예문**:

- 初めての担当だけに、手順を何度も確認した。 → 처음 맡은 업무이기 때문에 절차를 여러 번 확인했다.
- 期待が大きいだけに、結果を急がずに説明した。 → 기대가 큰 만큼 결과를 서두르지 않고 설명했다.

### G2-14. つつある — "~해 가고 있다"

**구조**: 동사 ます형 + つつある

**흔한 오류**: 지금 진행 중인 변화를 비교적 객관적으로 설명할 때 쓰며, 순간적인 행동에는 쓰지 않는다.

**예문**:

- 利用者の意見を受けて、案内の形が変わりつつある。 → 이용자의 의견을 받아 안내의 형태가 바뀌어 가고 있다.
- この地域では、公共サービスの利用方法が広がりつつある。 → 이 지역에서는 공공 서비스의 이용 방법이 넓어지고 있다.

### G2-15. わけがない — "~할 리가 없다"

**구조**: 보통형 + わけがない

**흔한 오류**: 강한 근거를 가지고 불가능하다고 판단할 때 쓰며, 단순한 희망 표현과는 다르다.

**예문**:

- 必要な書類を出さずに、申請が終わるわけがない。 → 필요한 서류를 내지 않고 신청이 끝날 리가 없다.
- 説明を聞かないで、内容を正しく理解できるわけがない。 → 설명을 듣지 않고 내용을 정확히 이해할 리가 없다.

### G2-16. ことはない — "~할 필요는 없다"

**구조**: 동사 사전형 + ことはない

**흔한 오류**: 하지 않아도 된다는 조언에 쓰며, 절대 일어나지 않는다는 뜻의 わけがない와 구별한다.

**예문**:

- 一人で課題を抱え込むことはない。 → 혼자서 과제를 떠안을 필요는 없다.
- 予定より早く着いたので、あわてることはない。 → 예정보다 일찍 도착했으니 서두를 필요는 없다.

### G2-17. にすぎない — "~에 지나지 않는다"

**구조**: 명사 / 보통형 + にすぎない

**흔한 오류**: 범위나 중요성을 한정할 때 쓰며, 상대의 노력을 가볍게 평가하는 데 함부로 쓰지 않는다.

**예문**:

- この数字は、利用状況を知るための一つの目安にすぎない。 → 이 숫자는 이용 상황을 알기 위한 하나의 기준에 지나지 않는다.
- 最初の提案は、話し合いを始めるための案にすぎない。 → 첫 제안은 논의를 시작하기 위한 안에 지나지 않는다.

### G2-18. とは限らない — "반드시 ~인 것은 아니다"

**구조**: 보통형 / 명사 + とは限らない

**흔한 오류**: 일반적인 경향에 예외가 있음을 말할 때 쓰며, 사실 전체를 부정하는 표현은 아니다.

**예문**:

- 利用時間が長い人が、内容をよく理解しているとは限らない。 → 이용 시간이 긴 사람이 내용을 잘 이해하고 있는 것은 아니다.
- 新しい方法が、いつも最も効率的だとは限らない。 → 새로운 방법이 언제나 가장 효율적인 것은 아니다.

### G2-19. にかかわらず — "~에 관계없이"

**구조**: 명사 + にかかわらず

**흔한 오류**: 서로 다른 조건에도 같은 기준이 적용됨을 말할 때 쓰며, 단순한 비교에는 쓰지 않는다.

**예문**:

- 経験の長さにかかわらず、全員が安全の説明を受ける。 → 경험의 길이에 관계없이 모두가 안전 설명을 받는다.
- 天気にかかわらず、窓口は予定どおり開きます。 → 날씨에 관계없이 창구는 예정대로 엽니다.

### G2-20. ものだから — "~이어서, ~때문에"

**구조**: 보통형 + ものだから

**흔한 오류**: 개인적인 사정이나 이유를 조심스럽게 덧붙일 때 쓰며, 공식 문서의 딱딱한 원인 설명에는 맞지 않을 수 있다.

**예문**:

- 道が混んでいたものだから、約束の時間に少し遅れた。 → 길이 막혔기 때문에 약속 시간에 조금 늦었다.
- 初めての場所だったものだから、受付を探すのに時間がかかった。 → 처음 가는 곳이어서 접수처를 찾는 데 시간이 걸렸다.
