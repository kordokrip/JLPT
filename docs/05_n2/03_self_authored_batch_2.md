청해는 먼저 대본과 확인 문제를 제공합니다. 재생 가능한 텍스트가 있고 Google 일본어 음성을 찾을 수 있으면 들을 수 있습니다. R2 activation·provenance·hash 계약은 발음 경로에 사용하지 않습니다.

## 카테고리 N2-U. 조건과 관점

### G2-21. に応じて — "~에 따라"

**구조**: 명사 + に応じて

**흔한 오류**: 조건이나 필요의 차이에 맞춰 대응한다는 뜻이며, 단순한 시간 순서를 나타내지 않는다.

**예문**:

- 経験に応じて、研修の内容を選びます。 → 경험에 따라 연수 내용을 고릅니다.
- 相談の目的に応じて、担当者が案内します。 → 상담 목적에 따라 담당자가 안내합니다.

### G2-22. に関して — "~에 관하여, ~에 대해"

**구조**: 명사 + に関して

**흔한 오류**: 사람에게 직접 하는 태도나 반응에는 に対して가 더 자연스럽고, 주제·사안에 관해 설명할 때 に関して를 쓴다.

**예문**:

- 利用方法に関して、質問をまとめて担当者に送った。 → 이용 방법에 관해 질문을 정리하여 담당자에게 보냈다.
- この制度に関する説明を、初めての人にも分かる形で用意した。 → 이 제도에 관한 설명을 처음인 사람도 알 수 있는 형태로 준비했다.

### G2-23. にわたって — "~에 걸쳐"

**구조**: 기간·범위 + にわたって

**흔한 오류**: 비교적 긴 기간이나 넓은 범위에 계속됨을 말할 때 쓴다.

**예문**:

- 工事は二か月にわたって行われる。 → 공사는 두 달에 걸쳐 진행된다.
- 調査では、複数の地域にわたって意見を集めた。 → 조사에서는 여러 지역에 걸쳐 의견을 모았다.

### G2-24. たとえ〜ても — "설령 ~해도"

**구조**: たとえ + 보통형/조건 + ても

**흔한 오류**: 가정이 바뀌어도 뒤의 판단이 변하지 않음을 강조한다.

**예문**:

- たとえ時間が短くても、要点を確認してから提出する。 → 설령 시간이 짧아도 요점을 확인한 뒤 제출한다.
- たとえ意見が違っても、互いに理由を聞くことが大切だ。 → 설령 의견이 달라도 서로 이유를 듣는 것이 중요하다.

### G2-25. にしても〜にしても — "~이든 ~이든"

**구조**: 명사/보통형 + にしても + 명사/보통형 + にしても

**흔한 오류**: 두 경우 모두에 공통된 결론을 말할 때 쓴다.

**예문**:

- 電車にしてもバスにしても、早めに出発したほうがいい。 → 전철이든 버스든 일찍 출발하는 편이 좋다.
- 更新するにしても解約するにしても、条件を確認してください。 → 갱신하든 해지하든 조건을 확인해 주세요.

### G2-26. につれて — "~함에 따라"

**구조**: 동사 사전형/명사 + につれて

**흔한 오류**: 한 변화와 함께 다른 변화가 자연스럽게 진행될 때 쓴다.

**예문**:

- 経験を重ねるにつれて、判断に余裕が出てきた。 → 경험을 쌓음에 따라 판단에 여유가 생겼다.
- 気温が下がるにつれて、暖房の需要が増える。 → 기온이 내려감에 따라 난방 수요가 늘어난다.

### G2-27. というより — "~라기보다"

**구조**: 보통형/명사 + というより

**흔한 오류**: 앞 표현을 완전히 부정하기보다 더 가까운 설명으로 고쳐 말한다.

**예문**:

- これは失敗というより、次の改善に必要な記録だ。 → 이것은 실패라기보다 다음 개선에 필요한 기록이다.
- 彼の説明は長いというより、具体例が多い。 → 그의 설명은 길다기보다 구체적인 예가 많다.

### G2-28. を問わず — "~을 불문하고"

**구조**: 명사 + を問わず

**흔한 오류**: 나이·성별·경험처럼 조건에 관계없이 적용됨을 격식 있게 말한다.

**예문**:

- 経験の有無を問わず、応募できます。 → 경험 유무를 불문하고 지원할 수 있습니다.
- 天候を問わず、案内は予定どおり行います。 → 날씨를 불문하고 안내는 예정대로 진행합니다.
