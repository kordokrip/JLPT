## 카테고리 N2-AB. 근거와 변화

### G2-29. に先立って — "~에 앞서"

**구조**: 명사 / 동사 사전형 + に先立って

**흔한 오류**: 중요한 일 전에 준비나 안내를 한다는 격식 있는 표현이다.

**예문**:

- 工事に先立って、周辺の住民へ説明会を開いた。 → 공사에 앞서 주변 주민에게 설명회를 열었다.
- 利用開始に先立って、必要な設定を確認してください。 → 이용 시작에 앞서 필요한 설정을 확인해 주세요.

### G2-30. を通じて — "~을 통하여, ~동안 내내"

**구조**: 명사 + を通じて

**흔한 오류**: 수단이나 전체 기간을 나타내며, 한 번의 짧은 행동에는 쓰지 않는다.

**예문**:

- 地域の会議を通じて、防災の意見を集めた。 → 지역 회의를 통해 방재 의견을 모았다.
- 一年を通じて、健康相談を受け付けている。 → 일 년 내내 건강 상담을 받고 있다.

### G2-31. に加えて — "~에 더하여"

**구조**: 명사 + に加えて

**흔한 오류**: 기존 요소에 새 요소가 더해짐을 말할 때 쓴다.

**예문**:

- 家賃に加えて、通勤にかかる費用も考える。 → 집세에 더하여 통근에 드는 비용도 생각한다.
- 紙の案内に加えて、短い動画も公開した。 → 종이 안내에 더하여 짧은 영상도 공개했다.

### G2-32. に比べて — "~에 비해"

**구조**: 명사 + に比べて

**흔한 오류**: 두 대상의 차이를 말할 때 기준을 분명히 한다.

**예문**:

- 去年に比べて、非常用の水を多く備蓄した。 → 작년에 비해 비상용 물을 많이 비축했다.
- 都会に比べて、この町は市場までの距離が短い。 → 도시에 비해 이 마을은 시장까지의 거리가 짧다.

### G2-33. に際して — "~할 때, ~에 즈음하여"

**구조**: 명사 / 동사 사전형 + に際して

**흔한 오류**: 특별하거나 공식적인 기회에 쓰며 일상적인 순간에는 다소 딱딱하다.

**예문**:

- 契約を結ぶに際して、条件を十分に確認した。 → 계약을 맺을 때 조건을 충분히 확인했다.
- 移転に際して、住所の変更を届け出る。 → 이전할 때 주소 변경을 신고한다.

### G2-34. とはいえ — "그렇다고는 해도"

**구조**: 보통형 / 명사 + とはいえ

**흔한 오류**: 앞 사실을 인정한 뒤 제한이나 다른 관점을 덧붙인다.

**예문**:

- 医療が進歩したとはいえ、予防は大切だ。 → 의료가 발전했다고는 해도 예방은 중요하다.
- 情報を公開したとはいえ、すべての人に伝わるわけではない。 → 정보를 공개했다고는 해도 모든 사람에게 전달되는 것은 아니다.

### G2-35. 一方で — "한편으로는"

**구조**: 보통형 / 명사 + 一方で

**흔한 오류**: 두 성질이나 결과를 대조해 함께 설명할 때 쓴다.

**예문**:

- 省エネは費用を減らす一方で、最初の設備投資が必要な場合もある。 → 에너지 절약은 비용을 줄이는 한편 처음 설비 투자가 필요한 경우도 있다.
- 市場が広がる一方で、流通の課題も増えている。 → 시장이 넓어지는 한편 유통 과제도 늘고 있다.

### G2-36. をめぐって — "~을 둘러싸고"

**구조**: 명사 + をめぐって

**흔한 오류**: 하나의 쟁점에 여러 사람의 의견·행동이 관련될 때 쓴다.

**예문**:

- 新しい制度をめぐって、住民の間で議論が続いている。 → 새 제도를 둘러싸고 주민 사이에서 논의가 계속되고 있다.
- 予算の使い方をめぐって、複数の案が出された。 → 예산 사용 방법을 둘러싸고 여러 안이 나왔다.
