이 문서는 개인 학습용 N2 네 번째 unit 묶음입니다. 어휘·문법 설명·예문·독해 지문·문제·해설·청해 대본은 모두 새로 작성했으며, 공식 JLPT 문항·정답·지문·음원을 포함하거나 변형하지 않습니다.

학습 화면은 재생 가능한 텍스트와 같은 언어의 일본어 브라우저 음성이 있으면 즉시 재생한다. Google 음성을 우선하며 R2 발음 자산·activation·fallback은 사용하지 않는다.

## 카테고리 N2-AF. 조건과 변화

### G2-37. に限って — "유독 ~에 한해서"

**구조**: 명사 + に限って

**흔한 오류**: 다른 경우와 달리 특정 경우만 예외임을 말할 때 쓴다.

**예문**:

- この端末に限って、認証に時間がかかる。 → 이 단말기에 한해서 인증에 시간이 걸린다.
- 締切前日に限って、問い合わせが増える。 → 마감 전날에 한해서 문의가 늘어난다.

### G2-38. に当たって — "~에 즈음하여"

**구조**: 명사 / 동사 사전형 + に当たって

**흔한 오류**: 중요한 시작·실행의 시점을 격식 있게 나타낸다.

**예문**:

- 新しいサービスの導入に当たって、権限を見直す。 → 새 서비스를 도입하면서 권한을 재검토한다.
- 申請を始めるに当たって、仕様を読む。 → 신청을 시작하면서 사양을 읽는다.

### G2-39. ものとして — "~라고 보고, ~을 전제로 하여"

**구조**: 보통형 + ものとして

**흔한 오류**: 사실·규칙을 전제로 판단하거나 설명할 때 쓴다.

**예문**:

- 利用者は案内を読んだものとして、次の画面を表示する。 → 이용자가 안내를 읽었다고 보고 다음 화면을 표시한다.
- 稼働中のサービスであるものとして、保守の時間を決める。 → 가동 중인 서비스라고 보고 유지보수 시간을 정한다.

### G2-40. にかけて — "~에서 ~에 걸쳐"

**구조**: 명사 + にかけて

**흔한 오류**: 시간·장소·범위가 이어짐을 나타낸다.

**예문**:

- 月曜から水曜にかけて、再起動の作業を行う。 → 월요일부터 수요일에 걸쳐 재시작 작업을 한다.
- 受付から結果の告知にかけて、履歴を保存する。 → 접수부터 결과 공지에 걸쳐 이력을 저장한다.

### G2-41. おそれがある — "~할 우려가 있다"

**구조**: 동사 사전형 / 명사 + のおそれがある

**흔한 오류**: 좋지 않은 결과가 일어날 가능성을 격식 있게 말한다.

**예문**:

- 更新を忘れると、サービスが利用できなくなるおそれがある。 → 업데이트를 잊으면 서비스를 이용할 수 없게 될 우려가 있다.
- 説明が不足すると、利用者に誤解を与えるおそれがある。 → 설명이 부족하면 이용자에게 오해를 줄 우려가 있다.

### G2-42. ことから — "~라는 점에서, ~이므로"

**구조**: 보통형 + ことから

**흔한 오류**: 관찰한 사실을 근거로 판단이나 추측을 말할 때 쓴다.

**예문**:

- 問い合わせが急に増えたことから、設定に問題があると考えた。 → 문의가 갑자기 늘어난 점에서 설정에 문제가 있다고 생각했다.
- 利用時間が短いことから、手順が分かりにくい可能性がある。 → 이용 시간이 짧은 점에서 절차를 알기 어려울 가능성이 있다.
