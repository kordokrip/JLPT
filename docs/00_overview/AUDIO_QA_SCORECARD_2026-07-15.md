이 문서는 준비 상태 기록이다. 실제 청감은 `/audio-qa`에서 후보를 재생하고 5개 항목을 입력한 뒤 Markdown으로 내보낸 결과로 이 파일을 갱신한다. 평가자나 점수를 추정해 채우지 않는다.

## 후보 준비 상태

2026-07-15 production 공개 HEAD를 같은 30문장에 대해 읽기 전용 확인했다.

| Provider | 가용 표본 | Model | Voice | Version | 판정 |
| --- | ---: | --- | --- | --- | --- |
| browser | device 의존 | 평가 시 자동 기록 | 평가 시 선택 voice | Web Speech API | 평가 device에서 확인 필요 |
| cloudflare | 30/30 | 기존 배포본 metadata 미노출 | 해당 없음 | 기존 배포본 metadata 미노출 | 후보 파일 있음, 새 HEAD 명세 배포 후 식별 필요 |
| google | 0/30 | `ja-JP-Neural2-B` 예정 | `ja-JP-Neural2-B` | `google-neural2-v1` | secret/승인 전, HTTP 400 |
| voicevox | 0/30 | 미확정 | speaker 미확정 | `voicevox-v1` 예정 | Engine URL/후보 없음, HTTP 404 |

완료 조건은 4 provider × 30문장 = 120개 평가 모두에 자연스러움, 피치 악센트, 장음·촉음·모라, 문장 억양, 잡음·속도 1~5점과 실제 후보 metadata가 있는 것이다.
