## 카테고리 N1-U. 고급 논리 표현

### G4-1. に照らして — "~에 비추어"

**구조**: 명사 + に照らして

**흔한 오류**: 기준·원칙·사실과 대조해 판단할 때 쓰며, 단순한 시간의 기준을 말하지 않는다.

**예문**:

- 公共性に照らして、再分配の基準を説明する。 → 공공성에 비추어 재분배 기준을 설명한다.
- 記録に照らして、当初の見解を見直した。 → 기록에 비추어 처음 견해를 재검토했다.

### G4-2. には及ばない — "~에는 미치지 못한다"

**구조**: 명사 + には及ばない

**흔한 오류**: 정도·범위·가치가 비교 대상에 닿지 못함을 비교적 격식 있게 나타낸다.

**예문**:

- この説明は先行研究の精度には及ばない。 → 이 설명은 선행 연구의 정밀도에는 미치지 못한다.
- 一時的な合意は、長期的な信頼には及ばない。 → 일시적 합의는 장기적 신뢰에는 미치지 못한다.

### G4-3. といえども — "~라고 해도"

**구조**: 명사 / 보통형 + といえども

**흔한 오류**: 앞의 사실을 인정하면서도 일반화할 수 없다는 제한을 문어적으로 덧붙인다.

**예문**:

- 多数意見といえども、少数者への影響を無視できない。 → 다수 의견이라고 해도 소수자에 대한 영향을 무시할 수 없다.
- 実績があるといえども、根拠を示さずに結論は出せない。 → 실적이 있다고 해도 근거 없이 결론을 낼 수 없다.

### G4-4. にあって — "~에 있어서, ~한 상황에서"

**구조**: 명사 + にあって

**흔한 오류**: 시대·상황·조직처럼 비교적 큰 배경 속의 판단이나 변화를 말할 때 쓴다.

**예문**:

- 情報が過剰な時代にあって、視座を選ぶ力が求められる。 → 정보가 과도한 시대에 관점을 고르는 힘이 요구된다.
- 不確実な状況にあっても、論証の手順は省けない。 → 불확실한 상황에서도 논증 절차는 생략할 수 없다.

### G4-5. に即して — "~에 맞추어, ~에 입각하여"

**구조**: 명사 + に即して

**흔한 오류**: 원칙을 그대로 반복하는 대신 실제 사실·조건에 맞게 적용할 때 쓴다.

**예문**:

- 地域の実情に即して、支援の方法を選ぶ。 → 지역의 실정에 맞추어 지원 방법을 고른다.
- 調査結果に即して、提案の優先順位を定める。 → 조사 결과에 맞추어 제안의 우선순위를 정한다.

### G4-6. を経て — "~을 거쳐"

**구조**: 명사 + を経て

**흔한 오류**: 시간·절차·변화를 통과한 뒤의 결과를 나타내며, 단순한 장소 이동에는 쓰지 않는다.

**예문**:

- 複数回の討議を経て、合意形成の案がまとまった。 → 여러 차례 토의를 거쳐 합의 형성안이 정리됐다.
- 批判的な検討を経て、命題の表現を改めた。 → 비판적 검토를 거쳐 명제의 표현을 고쳤다.
