## 카테고리 N1-Q. 고급 문법과 논리

### G3-1. にかたくない — "~하기 어렵지 않다"

**구조**: 동사 사전형 + にかたくない

**흔한 오류**: 상상·이해·추측이 쉽게 된다는 문어적 표현이다.

**예문**:

- 利用者が不安を感じたことは想像にかたくない。 → 이용자가 불안을 느낀 것은 상상하기 어렵지 않다.
- 資料が不足すれば、結論が揺らぐことは理解にかたくない。 → 자료가 부족하면 결론이 흔들리는 것은 이해하기 어렵지 않다.

### G3-2. に至って — "~에 이르러, ~이 되어 비로소"

**구조**: 명사 / 동사 사전형 + に至って

**흔한 오류**: 상황이 어떤 단계에 이른 뒤 생긴 변화·판단을 나타낸다.

**예문**:

- 議論が紛糾するに至って、第三者の裁定を求めた。 → 논의가 복잡해진 데 이르러 제3자의 판정을 요청했다.
- 事態がここに至って、前提を精査する必要が明らかになった。 → 사태가 이 지경에 이르러 전제를 정밀 조사할 필요가 분명해졌다.

### G3-3. を踏まえて — "~을 바탕으로"

**구조**: 명사 + を踏まえて

**흔한 오류**: 이미 확인한 사실·의견을 근거로 다음 판단을 말할 때 쓴다.

**예문**:

- 調査結果を踏まえて、規制の効果を検証する。 → 조사 결과를 바탕으로 규제 효과를 검증한다.
- 反論も踏まえて、論旨をより明確にした。 → 반론도 바탕으로 논지를 더 명확하게 했다.

### G3-4. そばから — "~하자마자 또"

**구조**: 동사 사전형 / 과거형 + そばから

**흔한 오류**: 한 행동을 하자마자 반대되는 일이 반복됨을 나타낸다.

**예문**:

- 説明したそばから、同じ質問が寄せられた。 → 설명하자마자 같은 질문이 들어왔다.
- 更新するそばから古い情報が共有されてしまう。 → 업데이트하자마자 오래된 정보가 공유되어 버린다.

### G3-5. 極まる — "지극하다, 매우 심하다"

**구조**: 명사 / な형용사 어간 + 極まる

**흔한 오류**: 주로 좋지 않거나 매우 강한 상태를 문어적으로 강조한다.

**예문**:

- 根拠を示さない結論は不十分極まる。 → 근거를 보이지 않는 결론은 지극히 불충분하다.
- 利用者を無視する運用は不親切極まる。 → 이용자를 무시하는 운영은 지극히 불친절하다.

### G3-6. とはいえ — "그렇다고는 해도"

**구조**: 보통형 / 명사 + とはいえ

**흔한 오류**: 앞의 사실을 인정하면서도 제한·반대 관점을 덧붙인다.

**예문**:

- 規制を緩めたとはいえ、安全への配慮は欠かせない。 → 규제를 완화했다고는 해도 안전에 대한 배려는 빼놓을 수 없다.
- 数字が改善したとはいえ、格差がなくなったわけではない。 → 수치가 개선됐다고는 해도 격차가 없어진 것은 아니다.
