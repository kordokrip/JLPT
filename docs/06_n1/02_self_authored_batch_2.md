## 카테고리 N1-M. 고급 문법과 논리

### G2-1. いかに〜ても — "아무리 ~해도"

**구조**: いかに + 동사·형용사 て형 + も

**흔한 오류**: 정도가 매우 커도 뒤의 결과가 바뀌지 않음을 격식 있게 나타낸다.

**예문**:

- いかに説明を重ねても、根拠が不十分なら納得は得られない。 → 아무리 설명을 거듭해도 근거가 부족하면 납득을 얻을 수 없다.
- いかに便利でも、個人情報の扱いには慎重であるべきだ。 → 아무리 편리해도 개인정보 취급에는 신중해야 한다.

### G2-2. を禁じ得ない — "~을 금할 수 없다"

**구조**: 명사 + を禁じ得ない

**흔한 오류**: 놀라움·우려·감동처럼 억누르기 어려운 감정을 문어적으로 표현한다.

**예문**:

- この大きな格差を見て、懸念を禁じ得ない。 → 이 큰 격차를 보고 우려를 금할 수 없다.
- 結果の偏りには驚きを禁じ得なかった。 → 결과의 편향에는 놀라움을 금할 수 없었다.

### G2-3. にもまして — "~보다도 더"

**구조**: 명사 + にもまして

**흔한 오류**: 비교 대상보다 정도가 더 큼을 강조한다.

**예문**:

- 今回は速度にもまして、透明性が求められている。 → 이번에는 속도보다도 투명성이 요구되고 있다.
- 過去にもまして、連携の重要性が高まっている。 → 과거보다도 연계의 중요성이 높아지고 있다.

### G2-4. をものともせず — "~을 아랑곳하지 않고"

**구조**: 명사 + をものともせず

**흔한 오류**: 어려움·장애를 두려워하지 않고 행동함을 표현한다.

**예문**:

- 担当者は困難をものともせず、復旧作業を続けた。 → 담당자는 어려움을 아랑곳하지 않고 복구 작업을 계속했다.
- 反対意見をものともせず進めるのではなく、まず審議を尽くす。 → 반대 의견을 아랑곳하지 않고 추진하기보다 먼저 심의를 다한다.

### G2-5. そびれる — "~할 기회를 놓치다"

**구조**: 동사 연용형 + そびれる

**흔한 오류**: 하려 했지만 타이밍이나 사정 때문에 끝내 하지 못했음을 나타낸다.

**예문**:

- 忙しくて、報告書を読みそびれてしまった。 → 바빠서 보고서를 읽을 기회를 놓쳐 버렸다.
- 質問の機会を逃さず、聞きそびれた点を確認した。 → 질문 기회를 놓치지 않고 미처 묻지 못한 점을 확인했다.

### G2-6. にひきかえ — "~와는 대조적으로"

**구조**: 명사 + にひきかえ

**흔한 오류**: 앞뒤의 차이를 객관적으로 대비할 때 쓴다.

**예문**:

- 都市部の増加にひきかえ、地方では利用者が減っている。 → 도시부 증가와는 대조적으로 지방에서는 이용자가 줄고 있다.
- 表面的な説明にひきかえ、資料は包括的だった。 → 표면적인 설명과 대조적으로 자료는 포괄적이었다.

### G2-7. をよそに — "~을 아랑곳하지 않고"

**구조**: 명사 + をよそに

**흔한 오류**: 주변의 기대·걱정·평가와 다른 행동이 계속됨을 나타낸다.

**예문**:

- 周囲の心配をよそに、彼は即座に結論を出した。 → 주변의 걱정을 아랑곳하지 않고 그는 즉시 결론을 냈다.
- 利用者の声をよそに施策を決めるべきではない。 → 이용자 목소리를 아랑곳하지 않고 시책을 정해서는 안 된다.

### G2-8. たるもの — "~인 사람이라면"

**구조**: 명사 + たるもの

**흔한 오류**: 직책·입장에 어울리는 책임이나 태도를 강조하는 격식 표현이다.

**예문**:

- 研究者たるもの、反証の可能性にも目を向けるべきだ。 → 연구자라면 반증 가능성에도 눈을 돌려야 한다.
- 責任者たるもの、権限と説明責任の両方を意識する。 → 책임자라면 권한과 설명 책임 양쪽을 의식한다.
