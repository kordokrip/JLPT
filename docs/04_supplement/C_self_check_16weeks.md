# 16주 자가 점검 가이드

기준일: 2026-08-09 KST. 이 문서는 선택 가능한 집중 학습 가이드다. DB의 기본 curriculum_weeks는 별도로 생성되는 52주 계획이며, 이 문서의 주차 수치가 현재 D1 seed 수나 공식 합격선을 뜻하지 않는다.

## 매일

- 앱의 due queue를 먼저 처리한다.
- 새 항목은 현재 여유에 맞춰 고르고, 완료한 뒤 해설·예문·짧은 산출 중 하나를 확인한다.
- 막힌 항목은 어휘, 문법, 읽기, 듣기, 쓰기 중 한 가지 원인만 기록한다.
- review rating은 실제 회상 난이도로 입력한다.

## 16주 단계

| 주차 | 초점 | 점검 질문 |
| --- | --- | --- |
| 1~4 | 문자·N5 기반과 학습 루프 | 매일 due를 처리하고 짧은 자기소개를 읽거나 말할 수 있는가? |
| 5~8 | N4 일상 표현과 연결 문장 | 시간·이유·비교를 구별해 예문을 만들 수 있는가? |
| 9~12 | N3 정보 연결과 독해 | 안내·메시지에서 핵심 정보와 근거를 찾을 수 있는가? |
| 13~16 | 약점 보완과 통합 복습 | 계속 틀리는 한 영역을 줄이고 due 누적을 관리했는가? |

TOPIK 트랙에서는 같은 주기를 적용하되, grade별 완료·due·review 수를 서버 progress에서 확인한다. N2/N1은 batch 단위로 학습하므로 문서의 예전 누적 수량을 목표로 삼지 않는다.

## 주간 회고

1. 새 카드보다 due 카드가 과도하게 쌓였는가?
2. 가장 자주 틀린 영역은 하나로 좁혀졌는가?
3. 다음 주에 줄일 새 항목 수와 유지할 복습량을 정했는가?
4. 발음 재생이 Google 음성만 사용하고 R2/비-Google fallback을 호출하지 않는가?

진단·모의 결과는 개인 학습 계획용이며 공식 JLPT/TOPIK 합격이나 점수를 예측하지 않는다.
